cosmos-live

Voice-directed live cameras.

Publishers put each camera in a LiveKit room. Ingestion turns the frames into searchable text. A voice agent switches the output to the feed that matches the ask.

Direct

Say the camera. The agent calls switch_feed.

Follow

A person leaves one view and shows up in another. The output follows.

Recall

Ask what happened. Search is over the vision chunks, not the raw video.

Operator output

The composited MJPEG stays on the machine that owns the cameras.

localhost:9090/stream

Run

  1. uv run python -m cosmos_live.ingestion_app
  2. uv run python -m cosmos_live.retrieval_app console
  3. uv run python -m cosmos_live.publisher_app --identity cam1 --camera-index 0
